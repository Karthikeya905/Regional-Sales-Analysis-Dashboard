# Regional Sales Analysis Dashboard

## Project Overview

An interactive **Power BI dashboard** developed to analyze regional sales performance and identify key business trends and insights.

## Tools Used

* Power BI
* Microsoft Excel
* Data Cleaning & Transformation
* Data Visualization

## Project Process

1. **Data Collection** – Used the regional sales dataset.
2. **Data Cleaning** – Cleaned and prepared the data for analysis.
3. **Data Analysis** – Analyzed sales, revenue, profit, products, and regions.
4. **Dashboard Creation** – Developed an interactive Power BI dashboard.
5. **Insights** – Identified important sales trends and regional performance.

## Key Analysis

* Regional sales performance
* Revenue and profit analysis
* Product performance
* Sales trends
* Key performance indicators (KPIs)

## My Contribution

* Cleaned and prepared the sales dataset.
* Analyzed the data and identified key trends.
* Created the Power BI dashboard and visualizations.
* Developed KPIs and business insights.

## Conclusion

The dashboard provides a clear overview of regional sales performance and helps identify important trends, profitable areas, and opportunities for data-driven business decisions.
